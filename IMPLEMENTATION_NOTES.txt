mpvRx visual customization update
=================================

Reference mapping
-----------------
- pro1: customization screen layout: preview first, three category tabs, a two-column card-style gallery, and persistent Apply/Cancel actions at the bottom.
- pro2: folder-icon selection and visual-style gallery arrangement.
- pro3: the independent folder-icon catalog.

Implemented in this patch
-------------------------
1. Card layout catalog expanded from 20 to 40 independently drawn Compose Canvas styles.
   - Existing IDs 0..19 are preserved for saved preferences and compatibility.
   - New IDs 20..39 add Prism Edge, Aurora Ribbon, Double Orbit, Hologram Scan,
     Frosted Capsule, Ribbon Fold, Hexagon Frame, Wave Cut, Circuit Trace,
     Soft Clay, Chrome Bezel, Neon Rails, Corner Brackets, Gradient Mesh,
     Paper Stack, Pixel Mosaic, Arc Halo, Diagonal Glass, Velvet Inset,
     and Spectrum Rail.
   - New designs have individual vector paths and/or dedicated Canvas geometry,
     not just alternate color palettes.
2. Random card-layout selection now covers IDs 0..39 independently for folders,
   videos, and episodes.
3. Customization screen shows the folder icon catalog before the card-layout
   gallery when the Folder tab is active, following the pro1/pro2 information order.
4. Card-layout previews now contain miniature folder/video content so the frame
   geometry is judged with visible content, not as empty colored strips.
5. Folder icon styles remain independent from card layout styles. Existing
   selectable folder-icon IDs are preserved (0..15 and 20..23); legacy IDs 16..19
   remain supported by the renderer.
6. Apply/Cancel actions and existing per-category accent, opacity, and random
   preferences are retained.

Validation
----------
- Static catalog check: 40 unique card layout IDs (0..39).
- Static renderer check: all new IDs 20..39 have dedicated drawing branches.
- Static folder catalog check: 20 selectable folder icon styles.
- No local Gradle build was run. Android compilation and runtime appearance still
  require GitHub Actions / device verification.
